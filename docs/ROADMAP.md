# 路线图

版本按"能听 → 好听 → 好用"推进。每个版本结束时软件都是可用的，不是半成品。

## v0.1 — 最小可听（开发中）

目标：打开一个音频文件，听到声音。

- [x] Core 层接口定义（`Status`、`AudioFormat`、`Decoder`、`AudioOutput`）
- [x] Null 输出后端（按墙钟速度渲染，可在无声卡环境测试）
- [x] 冒烟测试（38 项断言）
- [ ] CMake 构建脚本跑通
- [ ] FFmpeg 解码后端
- [ ] WASAPI 输出后端（共享模式即可）
- [ ] Qt Quick 最小界面：打开文件、播放/暂停、进度条
- [ ] Windows 上能听到声音

## v0.2 — 能听整张专辑

目标：日常听歌不别扭。

- [ ] 播放列表（添加、移除、拖拽排序）
- [ ] 上一首/下一首、随机、循环（单曲/列表）
- [ ] 元数据读取（TagLib）：标题、艺术家、专辑、时长、封面
- [ ] 拖拽文件到窗口即播放
- [ ] 记住上次的音量、播放模式、窗口布局
- [ ] 键盘快捷键（空格播放/暂停、方向键跳转）
- [ ] 拖拽进度条时预览时间，松开才真正 seek

## v0.3 — 曲库

目标：不用每次手动找文件。

- [ ] SQLite 媒体库：扫描目录、增量更新、删除失效条目
- [ ] 按艺术家/专辑/文件夹浏览
- [ ] 搜索（标题、艺术家、专辑）
- [ ] 封面缓存（缩略图按需生成，不每次读原图）
- [ ] 播放统计（播放次数、最近播放）

## v0.4 — 音质

目标：发烧友愿意用。

- [ ] 10 段图形均衡器 + 预设
- [ ] WASAPI 独占模式（位精确）
- [ ] ReplayGain / EBU R128 响度扫描与归一化
- [ ] gapless 播放
- [ ] 交叉淡化（0–12 秒可调）
- [ ] 输出设备切换、采样率显示

## v0.5 — Android

目标：手机端可用。

- [ ] Qt for Android 构建（arm64-v8a）
- [ ] AAudio 输出后端
- [ ] 适配手机的 UI 布局（底部导航、大按钮、手势）
- [ ] 后台播放（前台服务 + 媒体通知）
- [ ] 锁屏/通知栏控制
- [ ] 通过 SAF 访问音乐目录
- [ ] 响应系统媒体按键与蓝牙耳机控制

## v0.6 — 打磨

- [ ] Material Design 3 完整主题（动态取色、明暗切换）
- [ ] 频谱可视化
- [ ] 歌词（LRC 内嵌/外挂）
- [ ] 睡眠定时器
- [ ] 多语言（中文、英文）
- [ ] 无障碍（屏幕阅读器、键盘导航全覆盖）

## v1.0 — 发布

- [ ] Windows 安装包（MSI 或便携版 zip）
- [ ] Android APK（F-Droid 与 GitHub Releases）
- [ ] 自动构建与发布流水线
- [ ] 用户文档

## 明确不做

- **串流与云端曲库。** 两端各自维护本地库，不做服务端。
- **在线音乐服务集成。** 不做 Spotify/网易云之类的对接。
- **视频播放。** 只做音乐。
- **社交功能。** 不做分享、评论、关注。
